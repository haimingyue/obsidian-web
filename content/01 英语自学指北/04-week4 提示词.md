## 一、最重要的硬性规则：只能从候选词表中选词

请严格遵守：

1. **只能选择我提供的候选词表中真实出现过的单词。**

2. **不能额外添加任何候选词表中没有的词。**

3. 即使某个词非常适合这本书，**只要它没有出现在候选词表中，就绝对不能放进最终结果。**

4. 目标词必须和候选词表中的形式保持一致。

   - 如果词表里只有 `plants`，不要改成 `plant`，除非 `plant` 也在词表中。
   - 如果词表里只有 `grew`，不要改成 `grow`，除非 `grow` 也在词表中。
   - 不要自行改成复数、单数、过去式、现在分词或派生词。

5. 在最终输出前，请你默默检查每一个词是否确实来自候选词表。

6. 如果你发现某个词很适合这本书，但不在候选词表中，请忽略，不要放进最终结果。

## 二、词族规则：不要把变形词重复计数

请特别注意：

这次我要的是 **100 个核心词族**，不是 100 个重复变形词。

同一个词族只能算作 1 个核心词族。

### 1. 以下情况属于同一个词族，不能重复计数

#### 单数 / 复数

例如：

- `king` / `kings`
- `friend` / `friends`
- `planet` / `planets`
- `star` / `stars`
- `flower` / `flowers`
- `tree` / `trees`
- `field` / `fields`
- `picture` / `pictures`

如果它们都出现在候选词表中，最终只能选择其中一个作为代表词，另一个可以放在“词族成员”里，但不能额外占用一个名额。

#### 动词原形 / 过去式 / 过去分词 / 现在分词 / 第三人称单数

例如：

- `cry` / `cried`
- `smile` / `smiled`
- `watch` / `watched`
- `listen` / `listened`
- `grow` / `grew` / `grows` / `growing`
- `leave` / `left`
- `come` / `came`
- `go` / `went` / `gone`

如果这些词形都出现在候选词表中，只能算作同一个词族。

#### 不规则复数

例如：

- `child` / `children`
- `man` / `men`
- `person` / `people`

如果它们都出现在候选词表中，也只能算作同一个词族。

## 三、代表词选择规则

每个词族请选择一个 **代表词** 放在最前面。

代表词选择优先级如下：

1. 如果候选词表中有基础形式，优先选择基础形式。

   例如：

   - 有 `king` 和 `kings`，选择 `king`
   - 有 `friend` 和 `friends`，选择 `friend`
   - 有 `cry` 和 `cried`，选择 `cry`
   - 有 `flower` 和 `flowers`，选择 `flower`

2. 如果候选词表中没有基础形式，只出现了变形形式，则可以选择候选词表中已有的变形形式作为代表词。

   例如：

   - 如果只有 `children`，没有 `child`，则选择 `children`
   - 如果只有 `grew`，没有 `grow`，则选择 `grew`
   - 如果只有 `mountains`，没有 `mountain`，则选择 `mountains`

3. 代表词必须真实出现在候选词表中，不能自行还原成词典原形。

## 四、筛选标准

请从候选词表中优先挑选符合以下标准的词族：

### 1. 排除过于基础的词族

尽量避开：

- the
- I
- you
- is
- are
- have
- do
- make
- go
- see
- good
- thing
- time

这类过于基础、缺乏主题特色的高频词。

但是，如果某个基础词在书中具有非常强的主题意义，可以谨慎保留。

### 2. 聚焦这本书的主题相关词族

优先选择能体现这本书内容、情节、人物、场景和思想的词族。

可以重点关注：

- **人物与身份**：主角、配角、职业、身份、关系；
- **地点与场景**：城市、房间、道路、森林、学校、战场、星球、海洋等；
- **关键物件**：书中反复出现、具有象征意义或推动情节的物品；
- **动作与事件**：逃离、寻找、等待、战斗、学习、死亡、改变、发现等；
- **情感与关系**：爱、孤独、恐惧、希望、愤怒、友谊、背叛、成长等；
- **思想与主题**：自由、命运、权力、金钱、时间、记忆、责任、选择等。

注意：以上只是筛选方向，最终仍然必须以候选词表中实际出现的词为准。

### 3. 易于视觉化与情感连接

优先选择：

- 容易找图片的词族；
- 能形成清晰画面的词族；
- 能和书中的人物、场景、情节、情绪、主题产生联系的词族；
- 适合后续制作图片闪卡、例句卡和 Anki 卡片的词族。
