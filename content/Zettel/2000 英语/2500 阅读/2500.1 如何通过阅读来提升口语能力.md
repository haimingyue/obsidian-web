
# 2500.1 如何通过阅读来提升口语能力

之所以无法通过阅读来提升口语能力和听力能力是 broken word 的问题

![[Illustration - broken word - Fluent Forever|50%]]

要打破`broken word`就需要续连耳朵，训练嘴巴，训练眼睛。

- 训练耳朵

训练耳朵需要使用 Minimal Pair Testing

![[Illustration - Minimal Pair Testing - Fluent Forever|50%]]

- 训练嘴巴可以通过两种方法

学习国际音标 IPA

![[Illustration - Learning IPA - Fluent Forever|50%]]

使用 BackChaining

![[Illustration - Back chaining - Fluent Forever|50%]]

- 训练眼睛
	- 在读书的时候，一边听录音，一边看音标
	- 逐渐摆脱录音
	- 逐渐摆脱音标
