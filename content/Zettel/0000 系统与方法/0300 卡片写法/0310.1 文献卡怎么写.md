文献卡的作用不是代替思考，也不是把原文搬进系统。  
文献卡是阅读过程中的**暂存区**，用于捕捉值得继续发展的内容。

一张好的文献卡，不追求完整，而追求两件事：

- 记录出处
- 留下后续可以继续长的触发点

文献卡应当尽量轻，尽量短，尽量快。  
它不是成品，而是中间站。

我写文献卡时，通常包含四个部分：

### 1. 来源信息

至少要能让我以后重新找到原文。  
包括：

- 书名 / 文章名
- 作者
- 页码 / 章节 / 链接
- 必要时加阅读日期

### 2. 原文要点

只摘最值得保留的点。  
不是见一句抄一句，而是只留：

- 有启发的定义
- 值得发展的观点
- 关键论证
- 有代表性的例子

### 3. 我的即时观察

这部分比摘录更重要。  
我需要写下：

- 这段话让我想到什么
- 它和我已有哪类知识有关
- 它可能进入哪棵树
- 它值得发展成什么正式卡片

### 4. 后续动作提示

如果一条笔记明显值得发展，我要顺手标记：

- 转主卡
- 待对比
- 待验证
- 待链接

文献卡不追求完整解释。  
如果我在文献卡上写得过长、过全，往往意味着我把“阅读过程”错当成了“正式写作”。

文献卡应该像火花，不像成品。

**推荐格式**

来源：  
作者 / 书名 / 页码

摘录或要点：  
一句或几句最关键内容

我的观察：  
这句话为什么重要  
它让我想到什么  
它未来可能接到哪里

动作：  
转主卡 / 待对比 / 待补证据 / 待链接

**可执行规则**

1. 文献卡一定带来源信息。
2. 只记最值得保留的点，不追求全面摘录。
3. 必须写自己的观察，不能只有原文。
4. 文献卡尽量短，避免提前展开成长文。
5. 值得发展的内容，标记后续动作。
6. 文献卡是中转站，不是终点站。

**判断句**  
如果一张文献卡只有摘录、没有我的观察，那它还不够好。

**依据提示**  
书里把 bibcard / bib notes 作为中转层：先记录阅读中的简短观察，再转成更完整的 main notes。
